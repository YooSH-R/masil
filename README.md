# A203 AIoT 프로젝트

## Commit Convention
| Type | 설명 |
| --- | --- |
| `✨ Feat` | `새로운 기능 추가` |
| `🐛 Fix` | `버그 수정` |
| `📝 Docs` | `문서 수정` |
| `⚡️ Style` | `코드 포맷팅, 세미콜론 수정, 코드 변경 없음` |
| `♻️ Refactor` | `코드 리팩토링` |
| `🧪 Test` | `테스트 코드 추가/수정` |
| `🏗️ Chore` | `빌드, 패키지, 설정 등 기타 변경` |
| `🎨 Design` | `UI, CSS 변경` |
| `💡 Comment` | `주석 추가 및 수정` |
| `✅ Init` | `프로젝트 초기 생성` |
| `🚚 Rename` | `파일 또는 폴더 이름 변경` |
| `🔥 Remove` | `파일 삭제` |

#### Tip
```
1. node js 설치
2. node -v / npm -v 로 버전 확인
3. npm i -g gitmoji-cli 로 깃모지 설치
4. gitmoji -c 로 깃모지 활용 (커밋메시지 편하게 남기기)
```
