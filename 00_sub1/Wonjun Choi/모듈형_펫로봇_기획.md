# 모듈형 펫로봇 기획

## 서비스명

포켓펫

## 한 줄 소개

집에서는 바퀴로 사용자를 따라다니고, 외출할 때는 얼굴, 성격, 기억이 담긴 코어를 떼어 가방에 달고 다니며, 귀가 후 하루의 기억을 몸체와 이어가는 모듈형 반려로봇입니다.

## 문제 정의

반려로봇은 집 안에서는 귀엽고 존재감이 있지만 외출할 때 함께하기 어렵습니다. 반대로 휴대폰 속 디지털 펫은 어디든 데려갈 수 있지만 집 안에서 실제로 움직이고 다가오는 느낌이 약합니다.

사용자가 원하는 것은 단순한 로봇 기능이 아니라 "같은 존재가 내 일상 안팎을 이어서 함께한다"는 감각입니다.

## 핵심 공감 포인트

- 집에 있는 로봇은 외출하는 순간 두고 가야 한다.
- 밖에서 있었던 일은 로봇과 공유되지 않는다.
- 디지털 펫은 편하지만 실제 공간에서 살아있는 느낌이 약하다.
- 혼자 사는 사람에게는 누군가가 집에서 반겨주고, 밖에서도 작은 존재로 따라오는 경험이 의미 있다.

## 타겟 사용자

1차 타겟은 1인 가구 대학생 또는 청년입니다.

이유는 6주 프로젝트에서 인터뷰와 사용성 테스트가 쉽고, 펫로봇의 감성 가치를 검증하기 좋기 때문입니다. 노인, 아동, 장기 입원 환자는 확장 타겟으로 둘 수 있지만 MVP에서는 과하게 의료나 돌봄으로 주장하지 않습니다.

## 핵심 컨셉

포켓펫은 두 부분으로 구성됩니다.

| 구성 | 역할 |
| --- | --- |
| 펫 코어 | 얼굴, 성격, 기억, 터치 반응, 진동, LED를 담당하는 작은 휴대 모듈 |
| 실내 바디 | 바퀴, 카메라/센서, 모터, 충전 기능을 가진 실내 이동 몸체 |

사용자가 집에 있을 때는 코어가 바디에 결합되어 실내를 돌아다닙니다. 외출할 때는 코어만 분리해 가방 클립이나 주머니에 넣고 다닙니다. 귀가 후 다시 결합하면 외출 중 기록된 활동이 실내 펫의 반응으로 이어집니다.

## 사용자 시나리오

### 1. 집 안

사용자가 이름을 부르거나 앱에서 호출하면 펫이 다가옵니다. 일정 거리 안에서 사용자를 따라다니고, 장애물이 있으면 멈춥니다. 평소에는 충전 도크 근처에서 대기합니다.

### 2. 외출 준비

사용자가 현관 근처에서 코어를 분리하면 바디는 자동으로 정지하고 도크 모드로 들어갑니다. 코어 화면은 실외 모드 표정으로 바뀌고, 짧은 진동으로 분리 성공을 알려줍니다.

### 3. 외출 중

코어는 가방 클립에 달거나 주머니에 넣습니다. 사용자가 만지면 표정과 진동으로 반응합니다. 휴대폰과 연동해 걸음 수, 위치, 사진 같은 기억 이벤트를 저장합니다.

### 4. 귀가 후

코어를 다시 바디에 결합하면 외출 기억이 동기화됩니다. 예를 들어 많이 걸은 날에는 피곤한 표정을 짓거나, 특정 장소에 다녀오면 그에 맞는 반응을 보여줍니다.

## MVP 기능

| 구분 | 기능 | 설명 |
| --- | --- | --- |
| 코어 | 분리형 얼굴 디스플레이 | 작은 화면에 표정 표시 |
| 코어 | 터치 반응 | 터치 시 표정, LED, 진동 반응 |
| 코어 | 결합 감지 | 자석/홀 센서 또는 접점으로 결합 상태 판단 |
| 코어 | 실외 모드 | 분리 시 자동으로 휴대 모드 전환 |
| 바디 | 실내 주행 | 2륜 차동 구동으로 이동 |
| 바디 | 사용자 추적 | 카메라/거리 센서 기반 근거리 따라가기 |
| 바디 | 장애물 정지 | 장애물 감지 시 정지 |
| 웹/앱 | 펫 상태 확인 | 결합/분리, 배터리, 현재 모드 표시 |
| 웹/앱 | 기억 기록 | 외출 기록, 걸음 수, 장소 메모 저장 |
| 백엔드 | 이벤트 저장 | 모드 변경, 터치, 외출 기록 저장 |

## MVP에서 제외할 기능

- 실외 자율주행
- 완전한 자유 대화 AI
- 얼굴 인식
- 의료/낙상 감지 주장
- 항상 켜진 마이크
- 4족 보행
- 복잡한 지도 생성

## 기술 구성

### 펫 코어

- ESP32-S3 또는 유사 MCU
- 소형 원형/사각 디스플레이
- IMU
- 터치 센서
- 진동 모터
- LED
- BLE
- 소형 LiPo 배터리
- 결합 감지용 홀 센서 또는 포고핀
- 자석 정렬 + 물리적 래치

### 실내 바디

- Raspberry Pi급 보드 또는 노트북 연동 보드
- 카메라, ToF, 초음파 센서 중 선택
- 2륜 차동 구동
- 모터 드라이버
- 배터리
- 충전 도크 또는 도크 시뮬레이션
- 범퍼 스위치

### 웹/백엔드

- 사용자/펫 프로필
- 코어 결합 상태
- 외출 기억 이벤트
- 배터리 및 모드 상태
- 간단한 대시보드

## 상태 정의

| 상태 | 설명 |
| --- | --- |
| DOCKED | 바디에 결합되어 대기 중 |
| HOME_ACTIVE | 집 안에서 반응하거나 따라다니는 중 |
| DETACHING | 코어 분리 감지 직후 전환 중 |
| OUTDOOR | 코어만 들고 외출 중 |
| RETURN_SYNC | 귀가 후 외출 기억 동기화 중 |
| ERROR | 결합 실패, 배터리 부족, 통신 실패 |

## 안전과 프라이버시

- 목걸이보다 가방 클립을 우선합니다. 목에 걸면 무게와 흔들림 문제가 생길 수 있습니다.
- 코어 목표 크기는 5~7cm, 무게는 100g 이하로 잡습니다.
- 자석은 정렬용으로만 쓰고, 실제 고정은 래치 구조를 사용합니다.
- 마이크는 버튼을 눌렀을 때만 켜는 방식으로 제한합니다.
- 위치 기록은 사용자가 켜고 끌 수 있어야 합니다.
- 사용자가 데이터 삭제를 할 수 있어야 합니다.
- 실내 주행 중 장애물을 감지하거나 사용자를 잃으면 즉시 멈춥니다.

## 6주 일정

| 주차 | 목표 |
| --- | --- |
| 1주차 | 사용자 인터뷰 5~8명, 핵심 시나리오 확정, 상태 정의 |
| 2주차 | 코어 목업/전자부품 선정, 바디 기구 설계 |
| 3주차 | 실내 주행, 호출, 따라가기, 결합 감지 구현 |
| 4주차 | 실외 코어 모드, 웹/PWA, 기억 이벤트 저장 구현 |
| 5주차 | 코어-바디-웹 통합, 안전 정지, 반복 결합 테스트 |
| 6주차 | 데모 polish, 발표 자료, 사용자 테스트 결과 정리 |

## 성공 지표

- 코어 결합/분리 인식 성공률 95% 이상
- 모드 전환 2초 이내
- 실내 따라가기 테스트 성공률 90% 이상
- 의도적 충돌 0회
- 기억 이벤트 동기화 성공률 95% 이상
- 실외 코어 배터리 4시간 이상 목표
- 사용자 테스트에서 "같은 펫이 이어지는 느낌" 5점 만점 4점 이상

## 발표에서 강조할 킥

기능은 "분리되는 로봇"이지만, 감정적 가치는 "관계가 끊기지 않는 펫"입니다.

데모는 다음 장면이 가장 좋습니다.

1. 집에서 펫이 사용자를 따라온다.
2. 현관에서 코어를 똑 떼면 표정이 바뀐다.
3. 가방에 달고 나가 터치하면 반응한다.
4. 다시 몸체에 꽂으면 외출 기억을 말하듯 반응한다.

이 흐름이 보이면 자율주행, 임베디드, 웹, 백엔드가 모두 자연스럽게 연결됩니다.
