## 현재 추천 방향

최종 기획은 `포켓펫`입니다.

집에서는 바퀴 달린 몸체가 사용자를 따라다니고, 외출할 때는 얼굴, 성격, 기억이 담긴 코어만 떼어 가방에 달고 다니는 모듈형 반려로봇입니다.

핵심은 "밖에 나가는 순간 버려지는 실내 로봇"과 "집에서는 존재감이 약한 디지털 펫" 사이의 빈틈을 해결하는 것입니다. 자율주행은 실내에서 사용자를 찾아오고 따라다니는 데 집중하고, 실외에서는 무리하게 자율주행하지 않고 휴대형 코어로 정체성과 기억을 이어갑니다.
