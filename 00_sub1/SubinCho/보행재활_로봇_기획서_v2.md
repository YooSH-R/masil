# 보행 재활 동행 로봇 기획서 v2 (가칭: 워크메이트 / WalkMate)

> "치료 세션이 끝난 뒤, 환자의 걷기를 지켜보는 사람은 없습니다.
> 처방된 걷기를 실행시키고, 지켜보고, 기록하는 병원 보행 재활 동행 로봇"

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 한 줄 정의 | 처방된 보행 훈련 시간에 환자를 찾아가, 처방 페이스로 동행하며, 낙상을 감지하고, 결과를 의료진에게 리포트하는 병원용 보행 재활 동행 로봇 |
| 도메인 | 재활의료기관·재활병동 (B2B) |
| 핵심 가치 | ① 보행 처방의 **실행** (스케줄 호출 + 페이스 동행) ② 보행의 **안전** (동행 감독 + 낙상 즉시 감지) ③ 회복의 **데이터화** (세션 리포트 → 의료진) |
| 형태 | 소형 자율주행 로봇 + 환자 손목 UWB 밴드 (병원 입원 팔찌 관행에 편승) |
| 포지셔닝 | 치료를 만드는 로봇이 아니라, **치료사의 '보행 감독' 업무를 분담하는 코봇** |

### 세 가지 근본 질문에 대한 답
- **왜 로봇인가?** 보행 감독은 물리적 동행이 필요한 업무이고, 그 인력이 구조적으로 부족하기 때문 (근거: 2장). 알림·앱은 동행하지도, 낙상을 목격하지도 못한다.
- **왜 자율주행(SLAM/Nav2)인가?** 로봇이 병실로 환자를 찾아가고, 여러 환자를 스케줄에 따라 순회하며, 정의된 재활 코스를 동행해야 하기 때문.
- **왜 (확장 시) 실외인가?** 회복 후기의 실생활 보행 적응(노면·방향 전환)은 원내 복도로 대체되지 않기 때문. 단, 근거 수준을 고려해 실외는 확장 모드로 위치시킴.

## 2. 기획 배경 — 근거 데이터

### 2.1 걷기 처방은 의료 표준이다
- 조기보행(early ambulation)은 수술 후 폐합병증 예방과 순환 촉진을 위한 표준 관리 항목. 주요 병원은 수술 당일부터 조기보행을 권장 (분당서울대병원 환자교육 자료 등).
- 정부는 수술·발병 후 기능회복 시기의 집중재활을 위해 재활의료기관 지정 제도를 운영, 제3기 기준 전국 71개소 지정 (2026.3~2029.2).
- 회복기 재활 대상 질환: 중추신경계(뇌·척수 손상), **근골격계(고관절·골반·대퇴 골절 및 치환술 등)**, 비사용증후군 — 본 기획의 주 타겟 환자군과 일치.

### 2.2 그러나 환자는 걷지 않는다 — "입원 중 저활동의 유행병"
- 입원 노인 환자는 입원 기간의 **83%를 침대에 누워** 보내며, 서 있거나 걷는 시간의 중앙값은 **하루 43분**. 그런데 그중 **77.8%는 독립 보행이 가능**한 상태였음 (가속도계 연속 측정 연구).
- 메타분석: 입원 환자는 시간의 87~100%를 침상·좌위로 보내며, 노인 환자의 일일 보행은 **1,200보 미만**.
- 원인 (현장 관찰 연구): 의료진은 이동을 중요하게 여기지만 의자 이동·기능 평가가 우선되고, **'걷기'는 환자 자발성에 방치**됨. 낙상 책임 정책 이후 병원이 오히려 보행을 억제하는 역설도 보고됨.

### 2.3 감독하 걷기는 효과가 입증된 개입이다 — 그러나 인력이 없다
- 미국 보훈병원 STRIDE(감독하 보행 프로그램): 참여자의 **92%가 집으로 퇴원** (일반 치료군 74%, p=.007), 이후 8개 병원 무작위 대조시험으로 요양시설 퇴원 감소 효과 확인.
- 그러나 프로그램 **참여율은 낮았고, 각 병원이 보행 동행 인력을 직접 확보·훈련**해야 했으며, 효과가 입증됐음에도 널리 보급되지 못함.
- → **효과는 증명, 병목은 인력.** 본 프로젝트는 이 인력 병목을 로봇으로 대체한다.

### 2.4 국내 인력 구조 — 보행 감독 인력은 제도상 존재하지 않는다
- 재활의료기관 지정 기준(최상위 등급): **물리치료사 1인당 환자 9명**, 간호사 1인당 6명, 재활의학과 전문의 1인당 40명.
- 치료사의 근무시간은 환자별 치료 세션으로 소진됨 → **세션 외 시간의 보행을 1:1 감독할 인력은 최고 등급 기관에도 없음.** 일반 급성기 병원은 치료사 배치 기준 자체가 없어 상황이 더 열악.
- 지방 기관은 현행 기준조차 인력 확보가 어려워 완화 요구가 지속되는 상황.

### 2.5 낙상 — 보행과 안전의 딜레마
- 국내 환자안전보고(KOPS) 기준 낙상은 환자안전사고 중 **49.6%로 1위** 유형 (2020), 보고된 낙상의 **11.2%가 사망 또는 장기·영구 손상**으로 이어짐.
- 노인 입원환자 낙상 분석: 낙상 유형 1위 **'보행 중'(35.9%)**, 발생 장소 1위 병실(47.9%). 보행·배회·화장실 이동 중 낙상이 위해가 큼.
- 병원은 낙상이 두려워 보행을 제한하고, 보행 부족은 회복을 늦춤 → **걷기와 안전이 맞교환되는 악순환.**
- → 본 로봇의 "동행 감독 + 실시간 낙상 감지 + 즉시 의료진 알림"은 걷기와 안전을 동시에 확보하는 구조.

### 핵심 문제 정의 (요약)
**보행 처방은 표준이고(2.1), 효과적 개입도 검증됐지만(2.3), 감독 인력이 구조적으로 없어(2.4) 환자는 걷지 않고(2.2), 걷다가 다친다(2.5).**

## 4. 기능 명세

### 4.1 실내 모드 — 메인 (SLAM / Nav2)

| # | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| I-1 | 병동 지도 작성 | 설치 시 SLAM으로 병동 맵핑, 웹에서 병실·코스·금지구역 라벨링 | **P0** |
| I-2 | 스케줄 기반 환자 호출 주행 | 처방 시간에 해당 병실로 Nav2 자율주행 → 보행 시간 알림 인터랙션 | **P0** |
| I-3 | 환자 식별 | 손목 UWB 밴드로 본인 확인 (입원 팔찌 관행에 편승, 오인 동행 방지) | **P0** |
| I-4 | 처방 페이스 동행 | 정의된 복도 코스를 처방 속도로 동행. UWB 거리 유지, 처짐 감지 시 감속·대기, 목표 시간/거리 카운트 | **P0** |
| I-5 | 낙상 감지 + 즉시 알림 | UWB 급변 + 비전 판단 → 스테이션(간호사)에 위치 포함 즉시 알림 (너스콜 연동 지향) | **P0** |
| I-6 | 멀티 환자 스케줄링 | 하루 스케줄에 따라 병실 순회 (Nav2 멀티골 + 스케줄러), 세션 간 충전 독 복귀 | **P0** |
| I-7 | 격려 인터랙션 | 세션 완료 리액션, 진행률 음성·사운드 피드백, 회피 어려운 환자 대상 단계적 재방문(보채기의 병원 버전) | P1 |
| I-8 | 심박 연동 안전 제어 | BLE 심박(밴드/워치) 기준 초과 시 휴식 유도 | P1 |
| I-9 | 장애물·보행자 회피 | 병동 복도 환경의 로컬 회피 (카트, 다른 환자) | **P0** |

| O-2 | 산책일지 | 자동 촬영 + 경로 지오태깅 → 감성 일지 생성 (입원 생활의 리텐션·만족도 장치) | P2 |

## 5. 기술 스택 및 아키텍처

| 영역 | 기술 | 담당 문제 |
|---|---|---|
| 실내 자율주행 | ROS2 + SLAM(LiDAR) + Nav2 + AMCL + 도킹 | 병동 맵핑, 병실 호출 주행, 코스 동행, 순회, 복귀 |
| 스케줄링/행동 | Behavior Tree + 세션 스케줄러 | 멀티 환자 순회, 호출→식별→동행→리포트 시퀀스 |
| 환자 측위 | UWB(DWM1001급) 거리 + 비전 베어링 융합 | 동행 거리 유지, 환자 식별(태그=신원), 처짐·이탈 감지 |
| 임베디드 | 손목 밴드(UWB+MCU+LiPo), 주행체 제어(STM32/RPi) | 저전력 태그, 모터·센서 제어 |
| AI | 낙상 감지(비전+UWB 급변), (P2) 일지 생성 | 안전 감시, 리포트 |
| 웹 | 처방 관리 + 대시보드 + 알림 | 치료사·전문의 서비스 |
| 통신 | 원내 Wi-Fi (병원 환경 = 상시 연결), 로컬 큐잉·재전송 | 리포트 업로드, 알림. 자율 기능은 100% 온보드 |

**설계 원칙**
- 핵심 루프(주행·동행·낙상 감지)는 전부 온보드 — 네트워크 두절 시에도 기능 저하 없음(알림만 지연).
- UWB는 거리+신원, 비전은 방향, LiDAR는 장애물 — 센서별 단일 책임 융합 구조.
- 환자와의 상대위치 제어(UWB)와 지도 기반 내비게이션(Nav2)의 이중 구조로 팀 역할 분담 명확.

## 6. 차별점

| 비교 대상 | 그들이 못 하는 것 |
|---|---|
| 헬스 앱·워치 알림 | 동행하지 못하고, 낙상을 목격하지 못하며, 무시하면 그만 |
| 보행 재활 로봇 (외골격·트레드밀형) | 고가 치료 장비 — '보행을 만드는' 카테고리. 본 로봇은 '걸을 수 있는 환자의 훈련량·감독'을 담당하는 저가 코봇으로 카테고리가 다름 |
| 병원 물류·안내 AMR | 운반·안내만 할 뿐 환자 개인 식별, 페이스 동행, 처방 연동, 임상 리포트 없음 |
| 인력 기반 STRIDE형 프로그램 | 효과는 입증됐으나 인력 확보가 병목 — 본 로봇이 그 병목을 대체 |

## 7. 시연 시나리오 (미니 병동: 병실 2 + 복도 + 스테이션)

1. **[처방]** 치료사 화면에서 "301호 환자, 10:00, 코스 A, 2.5km/h, 15분" 입력
2. **[호출]** 시간 도래 → 로봇이 SLAM 맵 기반으로 301호까지 자율주행, 보행 알림
3. **[식별·동행]** 시연자가 밴드 착용 → 인식 → 복도 코스를 처방 속도로 동행, 시연자가 처지면 로봇 감속·대기
4. **[낙상]** 시연자 낙상 연기 → 로봇 감지 → 스테이션 화면에 위치 포함 알림 발생
5. **[리포트]** 세션 종료 → 대시보드에 기록 자동 반영, 회복 곡선 그래프 갱신
6. **[순회]** 로봇이 다음 스케줄 병실(302호)로 이동 → 멀티 환자 운영 시연 → 충전 독 복귀

## 8. 리스크 및 대응

| 리스크 | 대응 |
|---|---|
| "기존 재활 로봇과 뭐가 다르냐" | 카테고리 구분 선제 제시: 치료 생성(외골격) vs 훈련량·감독(본 로봇). 가격대·역할이 다름 |
| "지탱이 필요한 환자는?" | 대상을 '보행 가능 판정 환자'로 명시. 부축은 스코프 외 — 낙상 시 의료진 3분 거리라는 병원 환경이 잔여 리스크를 관리 |
| 낙상 감지 오탐/미탐 | 앉기·숙임과의 구분을 UWB 높이+비전 이중 판단, 미탐보다 오탐 허용 방향으로 튜닝(알림 후 확인) |
| 의료기기 규제 인접 | '치료'가 아닌 '훈련 보조·모니터링' 포지셔닝 일관 유지, 처방 판단은 항상 의료진 |
| 병동 환경 변수 (카트, 보행기, 사람) | 로컬 회피 P0 + 코스를 저혼잡 시간대·구간으로 스케줄링 |
| 환자의 로봇 거부감 | 인터랙션 강도 설정, 치료사 개입 경로 유지 (로봇은 대체가 아닌 분담) |
| 실사용자 검증 부재 | 물리치료사·재활의학과 인터뷰 필수 과제화 (부록 질문지), SSAFY 채널 통한 병원 연결 타진 |

## 9. 확장 로드맵

- **P2 실외 모드**: 회복 후기 환자의 병원 부지 산책 동행 + 산책일지 (실생활 보행 적응)
- **너스콜/EMR 연동**: 병원 시스템과의 표준 연동 (시연은 자체 알림 화면으로 대체)
- **퇴원 후 연속성**: 재활의료기관의 방문재활 제도와 연계한 가정용 확장 (v1 기획의 홈 버전이 여기서 부활)
- **데이터 자산**: 코스·속도 표준화된 반복 측정 → 질환별 회복 곡선 벤치마크

## 부록. 현장 검증 인터뷰 질문지 (물리치료사 / 재활의학과)

**A. 인력 병목 가설 검증**
1. 치료사 1인당 환자 9명 기준인데, 치료 세션 외 시간에 환자 보행을 챙길 여력이 실제로 있으신가요?
2. 세션 외 시간의 환자 보행은 현재 누가, 어떻게 관리하나요? (아무도 안 한다면 그 이유는?)

**B. 저활동 실태 검증**
3. 환자분들이 처방·권고받은 만큼 실제로 걷나요? 안 걷는 환자는 주로 왜 안 걷던가요?
4. "많이 걸으세요"라는 권고의 실행률을 체감으로 말씀해주신다면?

**C. 낙상-보행 딜레마 검증**
5. 보행 중 낙상 우려 때문에 환자의 걷기를 제한하게 되는 경우가 있나요?
6. 병동에서 낙상이 발생하면 주로 어떤 상황(보행 중/침상 주변/화장실)인가요?

**D. 솔루션 수요 검증**
7. 세션 외 보행량·속도 데이터가 회진·처방에 주어진다면 활용하시겠어요? 어떤 지표가 가장 필요한가요?
8. 로봇이 보행 동행·감독·낙상 감지를 분담한다면, 가장 기대되는 점과 가장 우려되는 점은?
9. 이런 로봇이 병동에서 운영되려면 반드시 지켜야 할 조건이 있다면? (동선, 소음, 감염 관리 등)

**E. 구매 논리 검증 (관리자용)**
10. 병원 입장에서 이 로봇의 도입 근거로 낙상 감소·재원일수·치료사 효율 중 무엇이 가장 설득력 있을까요?
